# Notchly

> 长期开发目录：`/Users/macbpforlg/Desktop/AI时代/AI开发/Notchly _ macOS灵动岛`

一个面向带刘海 Mac 的音乐优先型「灵动岛」原型。待机状态与真实摄像头刘海连成一体，在刘海左右显示状态；鼠标首次悬停、点击、菜单栏图标或 `⌘⇧Space` 均会自动展开音乐详情。

Notchly 采用 **SwiftUI + AppKit**：SwiftUI 负责岛内界面，AppKit 负责菜单栏、无激活悬浮面板、多空间窗口行为与显示器定位。

> 状态：Alpha。支持 macOS 14 及更高版本；当前发行方向为官网 / GitHub Release 的 Developer ID 签名与公证包，尚不适合直接提交 Mac App Store。

## 运行

在 Xcode 中打开 `Notchly.xcodeproj`，选择 `Notchly` scheme 后运行。第一次点击日历卡片的蓝色按钮时，macOS 才会请求读取日历的授权。

也可以用命令行验证基础构建与核心逻辑测试：

```sh
swift build
swift test
xcodebuild -project Notchly.xcodeproj -scheme Notchly build
```

## 已完成的原生基础

- `NSPanel` 无激活悬浮面板，支持所有桌面空间与全屏辅助窗口；优先定位到带摄像头刘海的内建屏幕。
- 固定定位到具有摄像头刘海的内建显示器；显示器配置变化时自动重新定位。
- Carbon 系统级快捷键注册：`⌘⇧Space`。
- 原生登录项管理，可由用户在设置中启用开机自启动。
- 左键菜单栏图标显示或隐藏，右键可进入设置或退出应用。
- 菜单栏使用简洁的「胶囊 + 圆点」灵动岛剪影，在浅色和深色菜单栏下都保持清晰。
- 刘海采用两端状态：待机两翼与完整音乐详情；悬停后先播放连续形变，再自动显示完整内容，无需二次点击。
- 使用固定最大透明窗口，岛体在同一 SwiftUI 视图树内连续变形；动画期间不再反复调整 `NSPanel` 尺寸。
- 透明窗口区域自动穿透鼠标，不遮挡下方网页、菜单栏或窗口操作。
- 完整态已经移除概览卡片首页，改为专辑封面、歌曲信息、播放进度与控制组成的音乐详情。
- 提供频谱、波形、脉冲和唱片光晕四种音乐视觉动效，可在音乐详情或设置中切换。
- 播放进度、当前时间和总时长来自播放器真实状态；播放期间按固定频率同步。
- Apple Music 读取当前曲目的内置封面，Spotify 可加载播放器提供的封面地址，网易云兼容层尝试读取系统媒体封面。
- 脉冲和唱片光晕围绕专辑封面显示；频谱和波形位于歌曲信息区域。
- 点击岛外区域或按 `Esc` 自动收起，离开刘海后的收起时间可在设置中调整。
- 展开态齿轮提供快捷菜单：刷新播放状态、打开设置、重新启动或退出 Notchly；无需进入设置窗口即可完成常用维护操作。
- 音乐动效和交互设置会持久保存；所有授权仅在对应功能第一次使用时申请。
- 设置按「通用 / 灵动岛 / 歌词」重新分组，使用统一卡片、说明和值对齐，并在歌词页提供实时外观预览。
- “关于”页显示真实版本与构建号，提供更新状态、诊断信息、反馈模板和第三方许可入口。
- 音乐动效默认使用轻量模拟动画；可选开启“根据真实节拍律动（实验性）”，仅在播放期间通过 macOS 系统音频捕获接口在本机计算瞬时能量，不保存或上传音频。此功能会请求“屏幕与系统音频录制”权限，详见 [隐私说明](PRIVACY.md)。
- 已配置原生 macOS App Icon（生成式设计资产）。
- 收起态会持续轻量刷新播放器：播放或暂停时左侧显示真实封面（无法获取时显示音乐占位图），右侧保留所选音乐动效；没有音乐时显示音乐图标与“悬停”引导，不再只剩一块黑色区域。
- 已授权的播放器和日历会自动刷新；未授权服务不会触发隐式权限弹窗。
- 专注计时可从完整岛顶部的计时器入口开始、暂停、重新开始或重置；时长可在设置中配置为 5–120 分钟。
- 使用系统提供的左右刘海辅助区域计算真实摄像头宽度与高度；窗口从屏幕顶边开始，收起时在摄像头左右显示音乐或计时状态。
- 鼠标首次进入刘海状态区即自动展示完整面板；点击外部和 `Esc` 同样可控制。
- EventKit 按需读取下一场非全天日程。
- 通过用户授权的 Apple Events 自动识别并控制 Apple Music 与 Spotify 原生桌面版，支持上一曲、播放/暂停和下一曲；不支持 Chrome PWA。
- 网易云音乐、QQ音乐、酷狗音乐、酷我音乐和汽水音乐使用 macOS 系统正在播放信息兼容层读取歌曲、进度与封面，并执行上一曲、播放/暂停和下一曲。多播放器同时运行时优先匹配系统当前媒体会话；该兼容层在 App Store 发布前需要重新评估。
- 根据歌曲名、歌手和时长自动匹配网易云曲库的同步 LRC 歌词，并在歌曲信息区随播放进度逐句显示；切歌后自动更新并缓存结果。
- 对回传停留在 0 秒的播放器使用本地单调时钟续走进度，避免进度条冻结和歌词反复跳回；歌词独立显示在播放器左下角，不再覆盖音乐动效。
- 歌词状态层仅在正在播放且已取得歌词时以高频发布当前句与下一句，支持双行过渡、±3 秒偏移校准，作词/作曲等信息按原始时间轴保留。
- 独立桌面歌词支持单/双行错位排版、随时间推进的 KTV 渐变覆盖、四种主题、字号、背景透明度、拖动位置记忆和锁定穿透；悬停控制改为底部居中的轻量浮层，不再挤压歌词。
- KTV 覆盖色以高刷新率连续推进，长停顿或末句结束后会自动切换为间奏状态，避免已完成的覆盖长时间停留。
- 收起态收紧至刘海高度附近，展开态独立加宽至 520 pt，上下边缘使用连续弧形肩部；无音乐时显示 Hello 信息页。
- 播放器直接显示电池与日历入口，点击封面可返回当前音乐应用。
- 支持喝水和久坐本地定时通知，可分别设置间隔和开关。
- 紧凑刘海岛始终保留，不再提供会让鼠标入口消失的关闭选项。
- macOS 15.4 及更高版本通过随应用打包的 BSD-3-Clause `MediaRemoteAdapter` 兼容系统限制；用户不需要另外安装 Homebrew 或命令行工具。
- 不需要权限即可显示真实的内置电池电量、充电状态和剩余时间。
- 临时文件托盘支持把文件拖到刘海区域后复制到本地专用目录；可从展开页拖出、在 Finder 中定位或确认后一键清空，并可设置 1–30 天保存期限与 128–2048 MB 容量上限。
- App Sandbox、日历权限说明和刘海安全区兼容设置。

AirDrop 快捷入口尚未实现，将在文件暂存托盘完成实机验证后接入。

## 已知限制与发布路径

- 歌词搜索与同步 LRC 来自网易云音乐的公开接口，仅用于用户本机的播放伴随展示；接口可用性、歌词准确性及内容授权均不作保证。发布前须按目标市场核实歌词来源、版权和隐私说明。
- `MediaRemoteAdapter` 会调用 macOS 私有的 `MediaRemote.framework`。这与 Mac App Store 的发布规则存在明显风险，当前实现不应直接作为 App Store 上架版本提交。若选择 App Store，需要以公开 API 的能力替换或下线国内播放器兼容层；若选择官网分发，则仍需完成 Developer ID 签名、公证、更新机制和隐私说明。
- `dist/` 是本地构建产物，已由 `.gitignore` 排除。产品截图位于 `docs/使用截图/`，应在确认无个人或敏感内容后再单独提交。
