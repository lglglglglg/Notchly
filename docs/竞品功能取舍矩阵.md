## 交互收敛原则

Notchly 不采用“首页 + 文件 + 游戏 + 剪贴板 + 设置”的常驻顶部导航。入口由用户行为决定：

- 鼠标悬停：岛体连续形变并自动打开当前活动的 Nook。
- 点击：打开当前活动的 Nook 详情。
- 拖入文件：自动切到 Pocket 文件区。
- 快捷键：打开 Pocket 剪贴板或快捷应用。
- 重要事件：短暂覆盖当前活动，结束后回到原状态。

这样可以吸收竞品能力，同时保持日常界面仍然是一个专注、顺滑的音乐刘海。

## 权限与隐私边界

- 剪贴板历史默认本地存储，必须提供暂停、清空和排除 App。
- 文件暂存优先保存用户拖入文件的引用；需要跨启动访问时使用用户明确授权的安全作用域书签。
- 快捷启动只保存用户选择的 App，不上传应用列表。
- 实时活动只展示 Notchly 自己生成或通过公开接口取得的事件，不通过辅助功能或屏幕抓取偷读其他 App 通知。
