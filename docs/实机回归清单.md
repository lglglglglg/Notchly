# Notchly 实机回归清单

适用于每个 Alpha 发行包。自动测试通过后，至少在一台带刘海的 Mac 上完成以下检查，并记录 macOS 版本、应用版本和构建号。

## 启动与刘海交互

- 冷启动后，紧凑岛出现在内建刘海两侧，鼠标不被透明区域拦截。
- 悬停、菜单栏图标和 `⌘⇧Space` 都能展开；点击岛外或 `Esc` 能收起。
- 外接显示器连接、拔出及睡眠唤醒后，岛会回到内建屏幕并保持可交互。

## 播放器与歌词

- 分别用 Apple Music、Spotify 和任一系统媒体兼容播放器测试播放、暂停、上一曲、下一曲和打开来源应用。
- 在播放器短暂无响应时，岛的展开、收起和鼠标交互不能冻结；控制失败须显示可理解的提示。
- 切歌、暂停、拖动播放器进度后，封面、进度和歌词在合理时间内同步；无歌词和网络失败不应持续高频请求。
- 开启/关闭桌面歌词，检查锁定穿透、解锁热点、拖动位置记忆、KTV 覆盖和暂停后的动画停止。

## 文件托盘与系统服务

- 导入小文件、大文件、同名文件和目录；验证导入期间岛仍可操作、容量限制准确、重名副本不覆盖原件。
- 导入期间“一键清空”应不可用；导入成功、失败和容量不足都应给出正确状态。
- 日历授权拒绝/允许后，显示内容与提示正确；电池信息在展开和收起状态均可刷新。
- 专注、喝水和久坐提醒在开关切换后正确创建或取消。

## 发行验收

- 运行 `swift test`、无签名 Debug 构建和 Release 构建。
- 校验发行包中的版本号、构建号、签名和 `MediaRemoteAdapter` 资源完整性。
- 对外分发前，完成 Developer ID 签名、公证与隐私/私有 API 风险复核。
