Built for the notch

把零碎信息，收进一条自然的节奏。

每一项能力都围绕一个目标：减少打断，而不是再增加一个需要管理的窗口。

♫

多平台播放

支持 Apple Music、Spotify 与主流国内播放器，实时呈现歌曲、封面与进度。

≋

同步歌词

网易云音乐优先、LRCLIB 回退；歌词、署名与时间校准始终保持连贯。

⌘

自然交互

悬停、点击菜单栏图标或快捷键即可展开；需要时出现，不需要时退回刘海。

◌

原生动效

频谱、波形、脉冲与宇宙尘埃均为本地模拟，不读取系统音频。

◎

桌面歌词与专注

独立桌面歌词、专注计时、日历、电池与临时文件托盘随手可用。

⌁

本地优先

没有账号、广告或遥测；设置、缓存与专注状态均由你的 Mac 本地处理。

Interaction

不用寻找。
顺手就能到达。

Notchly 不占用 Dock，不抢占桌面。它只在刘海附近提供一个稳定、熟悉的入口。

⌘ ⇧ Space
展开或收起全局快捷键，随时切换灵动岛
鼠标悬停
自然展开进入刘海区域即可查看当前状态
Esc
立即收起结束查看，回到安静的紧凑状态

Privacy first

你在听什么，只属于你。

Notchly 不收集键盘、屏幕或系统音频；不提供广告、账号与遥测服务。需要访问的日历、自动化、通知和网络权限都有明确用途。
