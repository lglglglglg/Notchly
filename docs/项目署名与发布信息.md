# 项目署名与发布信息

本文档是韩十久工作室后续开源项目的署名与发布信息模板。新项目可复制本文件，再补充项目专属的版本、反馈渠道和隐私政策链接。

## 官方身份

- 工作室：韩十久工作室（Hanshijiu Studio）
- 维护者：Stephan Li
- 版权声明：`Copyright (c) 2026 Stephan Li (Hanshijiu Studio).`
- README 展示：`版权所有：© 2026 Stephan Li（韩十久工作室 · Hanshijiu Studio）`
- 公开反馈渠道：GitHub Issues
- 私密安全渠道：GitHub Private Vulnerability Reporting

## 开源协议

默认使用 MIT License。项目根目录的 `LICENSE` 必须保留完整协议正文，并将版权行替换为：

```text
Copyright (c) 2026 Stephan Li (Hanshijiu Studio).
```

## 客户端「关于」页

建议至少展示：

1. 当前版本与构建号；
2. 工作室：韩十久工作室（Hanshijiu Studio）；
3. 版权所有：© 2026 Stephan Li（韩十久工作室 · Hanshijiu Studio）；
4. 开源协议入口；
5. 隐私政策入口；
6. GitHub Issues 反馈入口；
7. GitHub 私密漏洞报告入口。

客户端不公开个人邮箱，也不直接嵌入 SMTP 或邮件服务凭据。后续如增加官网反馈表单，应通过带有人机验证、频率限制和内容校验的服务端转发。

## 隐私与反馈

- 隐私政策默认放在项目根目录 `PRIVACY.md`，并在客户端“关于”页提供查看入口。
- 反馈模板应包含版本号、构建号、系统版本和复现步骤，但不要自动收集账号密钥或其他敏感信息。
- 发布前检查 README、LICENSE、关于页和发行包内的文档署名是否一致。
