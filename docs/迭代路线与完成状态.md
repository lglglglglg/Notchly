# Notchly 迭代路线与完成状态

> 最后核验：2026-09-28。状态以当前仓库代码、自动测试和已完成的实机反馈为准，不以聊天中的设想作为完成依据。

状态含义：

- ✅ 已完成：代码、界面、文档和自动验证已落地。
- 🟡 部分完成：已有基础能力，但仍缺关键交互、实机验证或完整适配。
- ⬜ 未完成：当前代码尚未实现。
- 🚧 外部条件：需要证书、账号、新设备或长时间实机运行，不能只靠代码完成。
