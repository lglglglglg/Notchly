# Notchly 0.2.1 Alpha 验收清单

## 基础交互

- [ ] 内建屏幕的摄像头刘海左右出现音乐图标和动态指示，黑色区域与屏幕顶边、真实刘海连续。
- [ ] 鼠标移入刘海状态区只显示音乐快速预览，不会立即展示所有卡片。
- [ ] 点击刘海状态区或快速预览可以展开完整面板。
- [ ] 外形先展开，内容随后淡入，收起过程没有明显闪烁或位置跳变。
- [ ] `⌘⇧Space` 可以展开和收起。
- [ ] 点击面板外或按 `Esc` 可以收起。
- [ ] 菜单栏图标：左键切换；右键可打开设置和退出。
- [ ] 退出后状态条与面板都消失。

## 信息卡片

- [ ] 工作、音乐、演示和省电预设可正确套用；手动修改关联设置后自动显示为“自定义”。
- [ ] 省电预设下可选模块轮询和装饰动效停止，切换其他预设后正常恢复。
- [ ] 电池、专注、日历、提醒事项和文件暂存卡片可独立开关，播放/空闲界面立即同步并在重启后保留。
- [ ] 提醒事项模块默认关闭，只有启用并主动打开卡片后才申请权限；拒绝权限、空列表和逾期项目均有正确提示。
- [ ] 音乐展开区和待机面板可分别调整卡片顺序，重启后顺序仍保留且可恢复默认。
- [ ] 最近播放最多保留 50 首、相同歌曲不重复；清空最近播放不会清空收藏。
- [ ] 当前歌曲可收藏和取消收藏，重启应用后收藏仍保留，最多保留 100 首。
- [ ] 专注计时可开始、暂停、重置；重启应用后仍保持正确剩余时间。
- [ ] 计时结束时收到本地通知（允许通知后）。
- [ ] 点击日历卡刷新后显示下一场非全天日程（允许日历后）。
- [ ] Spotify 或 Music.app 播放时显示正确曲目；上一曲、播放/暂停、下一曲可用。
- [ ] Apple Music / Spotify 显示为 AppleScript 适配器，国内播放器显示为 MediaRemote 适配器；跨通道切换和控制路由正确。
- [ ] 国内播放器退出后 MediaRemote 监听停止，重新启动时只建立一个监听进程。
- [ ] 歌词源提供译文时显示原文与译文；关闭翻译或歌曲无译文时自动保持单语布局。
- [ ] 电源卡显示正确电量与充电状态。

## 显示环境

- [ ] 普通桌面和多个桌面空间下都可打开和收起；其他应用全屏时默认隐藏。
- [ ] 关闭“全屏时自动隐藏”后，灵动岛可在其他应用的 macOS 全屏空间显示。
- [ ] “智能 / 歌词 / 时间 / 极简”四种收起状态可立即切换，重启后保留选择。
- [ ] 长歌词会在收起空间内截断，无歌词、暂停和专注计时状态的回退内容正确。
- [ ] “内建屏 / 主屏 / 随鼠标”三种显示器策略都能正确定位，重启后保留选择。
- [ ] 无刘海外屏上的虚拟岛居中，点击和悬停区域与外观一致。
- [ ] 外屏热插拔、改变主屏和睡眠唤醒后仍可展开、收起和播放控制。
- [ ] 在设置中关闭任意卡片或收起状态条后，界面立即反映配置。
- [ ] 设置页可关闭悬停快速预览，并可调整自动收起时间。
