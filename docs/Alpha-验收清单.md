# Notchly 0.2.1 Alpha 验收清单

## 基础交互

- [ ] 内建屏幕的摄像头刘海左右出现音乐图标和动态指示，黑色区域与屏幕顶边、真实刘海连续。
- [ ] 鼠标移入刘海状态区只显示音乐快速预览，不会立即展示所有卡片。
- [ ] 点击刘海状态区或快速预览可以展开完整面板。
- [ ] 外形先展开，内容随后淡入，收起过程没有明显闪烁或位置跳变。
- [ ] `⌘⇧Space` 可以展开和收起。
- [ ] 点击面板外或按 `Esc` 可以收起。
- [ ] 菜单栏图标：左键切换；右键可打开设置和退出。
- [ ] 退出后状态条与面板都消失。

## 信息卡片

- [ ] 专注计时可开始、暂停、重置；重启应用后仍保持正确剩余时间。
- [ ] 计时结束时收到本地通知（允许通知后）。
- [ ] 点击日历卡刷新后显示下一场非全天日程（允许日历后）。
- [ ] Spotify 或 Music.app 播放时显示正确曲目；上一曲、播放/暂停、下一曲可用。
- [ ] 电源卡显示正确电量与充电状态。

## 显示环境

- [ ] 普通桌面、全屏应用、多个桌面空间下都可打开和收起。
- [ ] 连接外接显示器后，面板仍固定出现在带刘海的内建显示器。
- [ ] 在设置中关闭任意卡片或收起状态条后，界面立即反映配置。
- [ ] 设置页可关闭悬停快速预览，并可调整自动收起时间。

请记录：发生场景、预期结果、实际结果、是否能稳定复现；如有可能附上截图或屏幕录制。
